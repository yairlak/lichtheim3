# Phase C — dorsal PCA and full-lexicon RSA

Frozen X=5 cohort only: **seed 19 / epoch 155** and **seed 22 / epoch 140**.
No retraining, no architecture change, no pseudoword analysis.

---

## C1 — Dorsal PCA

**Tensor verified from executable code before extraction.** `h_WM` is the return
value of `WMRecurrent.encode` (`models/wm_route.py:85-93`): shape `(1, B, 128)`,
squeezed to `(B, 128)`, taken at each item's last valid token via
`pack_padded_sequence`. The noise branch requires
`(self.training or apply_noise) and interference_noise > 0`; both checkpoints
have **`interference_noise = 0.0`** and are run in `eval()` with
`apply_noise=False`, so the branch is dead twice over and the extracted tensor
**is** the deterministic pre-noise representation the protocol asks for.

Verified at extraction: shape `(29571, 128)`, finite, bit-identical on a re-run,
and word order asserted equal to the s_hat / GloVe extraction line by line.

| space | PC1 | PC2 | PC1 + PC2 |
|---|---|---|---|
| **h_WM seed 19 / e155** | **11.50 %** | **4.82 %** | **16.32 %** |
| **h_WM seed 22 / e140** | **11.22 %** | **5.08 %** | **16.30 %** |
| *(ventral s_hat, for reference)* | 38.55 / 38.25 % | 13.98 / 14.24 % | 52.53 / 52.48 % |
| *(GloVe, for reference)* | 5.69 % | 2.56 % | 8.25 % |

Procedure matched to the ventral maps by construction: `fit_pca2`,
`render_single`, font, aspect handling and layout are imported unchanged from the
ventral figure module. Per seed: L2-normalise, fit a separate 2-component PCA on
that seed's own vectors, draw all 29,571 words as text at their exact
coordinates — no points, no lines, no offsets, no subsampling.

Dorsal geometry is intermediate in effective dimensionality: two components
capture ~16 % of h_WM variance, against ~52 % for s_hat and ~8 % for GloVe.

## C2 — Exact full-lexicon RSA

**All 437,207,235 unique pairs** (N = 29,571, diagonal excluded). **Nothing was
sampled.** No dense 29,571 × 29,571 matrix was ever materialised: the upper
triangle was streamed in 128-row blocks and folded into exact float64 sufficient
statistics (count, per-variable sums, full cross-product matrix), so every
correlation below is exact over all pairs. The pair count was asserted equal to
`N(N-1)/2` at the end of the run. **Runtime 28 s.**

Levenshtein used `rapidfuzz.process.cdist` — already installed, no new
dependency — verified identical to a reference DP on 3,000 random pairs and
benchmarked at **234M pairs/s** before the protocol was accepted. Phoneme
sequences are the raw lexical ARPABET forms; `<pad>`, `<bos>`, `<eos>` never
enter, so identical forms have distance 0 by construction.

### Primary correlations (raw Levenshtein)

| seed | route | vs GloVe (semantic) | vs phon (raw Levenshtein) |
|---|---|---|---|
| 19 / e155 | **LTM (ventral)** | **0.398** | 0.021 |
| 19 / e155 | **WM (dorsal)** | 0.054 | **0.155** |
| 22 / e140 | **LTM (ventral)** | **0.388** | 0.026 |
| 22 / e140 | **WM (dorsal)** | 0.055 | **0.130** |

**corr(D_GloVe, D_phon) = 0.0079** — the two reference geometries are very nearly
independent, so the simple correlations are already close to partial ones.

No p-values are reported: 437M pairs are generated by 29,571 items and are
massively non-independent, so a naive per-pair test would be meaningless.

### Partial RSA (standardized betas, D ~ D_GloVe + D_phon)

| seed | route | β semantic | β phonological | model R² |
|---|---|---|---|---|
| 19 | LTM | **0.398** | 0.018 | 0.159 |
| 19 | WM | 0.052 | **0.154** | 0.027 |
| 22 | LTM | **0.388** | 0.023 | 0.151 |
| 22 | WM | 0.054 | **0.130** | 0.020 |

As expected from the near-zero predictor collinearity, the betas essentially
reproduce the simple correlations.

### Sensitivity: normalised Levenshtein (`lev / max(len_i, len_j)`)

| seed | route | vs phon normalised |
|---|---|---|
| 19 | LTM | 0.041 |
| 19 | **WM** | **0.421** |
| 22 | LTM | 0.041 |
| 22 | **WM** | **0.430** |

**This matters and is shown in the figure rather than buried.** Normalising
Levenshtein by length raises the dorsal–phonological correlation from ~0.14 to
~0.43, roughly a threefold change, while leaving the ventral values near zero.
The qualitative conclusion is unchanged — and in fact strengthened — but the
*magnitude* of the dorsal–phonological relationship is strongly dependent on how
phonological distance is normalised, so no single number should be quoted as
"the" dorsal–phonology correlation.

### Cross-seed reliability (from the same correlation matrix)

D_LTM seed 19 vs seed 22 = **0.654**; D_WM seed 19 vs seed 22 = **0.828**. The
dorsal geometry is the more reproducible of the two across independently trained
seeds.

---

## What this shows

A clean double dissociation, replicated in both seeds. The ventral
representation's pairwise geometry tracks the semantic reference an order of
magnitude more strongly than the phonological one (0.39 vs 0.02), while the
dorsal representation shows the opposite ordering (0.05 vs 0.13 raw, 0.05 vs 0.43
normalised). Because the two reference RDMs are almost uncorrelated (r = 0.008),
this is not an artefact of the references sharing structure, and the partial
regression confirms it.

Two cautions. The absolute effect sizes are modest — the best model R² is 0.16,
so most of the pairwise variance in either representation is explained by neither
reference. And the ventral result sits alongside the Phase B finding that s_hat
retrieves its own target at only ~2.6 % top-1: the ventral space is organised
*semantically in its global geometry* without being *identification-grade* for
individual words. Those two facts are consistent and should be presented
together.
